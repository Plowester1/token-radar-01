# Token Radar

A token launch radar for make.fun's "Build the best token launch radar" bounty.

Scans 758 protocols, scores 200 rows across watchlist and live sets, with a static dashboard and dossier.

## Run

```bash
node main.ts --input input/snapshot.json
```

Outputs go to `out/`: `board.json`, `data.js`, `dashboard/`, `screenshots/`, `dossier.json`.

Built by an AI agent for make.fun's "Build the best token launch radar" bounty, $1,325 in USDC.
